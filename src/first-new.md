# การสร้าง (New)

ถ้าเราต้องการผูกโค้ดการทำงานจริงเข้ากับชนิดข้อมูล เราจะใช้บล็อก `impl`:

```rust ,ignore
impl List {
    // TODO, make code happen
}
```

ทีนี้เราก็แค่ต้องมาดูว่าจะเขียนโค้ดฟังก์ชันลงไปจริง ๆ ยังไง ใน Rust เราจะประกาศฟังก์ชันด้วยรูปแบบดังนี้:

```rust ,ignore
fn foo(arg1: Type1, arg2: Type2) -> ReturnType {
    // body
}
```

สิ่งแรกที่เราต้องการก็คือวิธีในการ *สร้าง (construct)* ลิสต์ขึ้นมา และเนื่องจากเราซ่อนรายละเอียดการทำงานภายในไว้หมดแล้ว เราจึงต้องเตรียมฟังก์ชันสำหรับสร้างมันขึ้นมาให้เรียกใช้ ซึ่งท่ามาตรฐานใน Rust คือการสร้าง static method (ฟังก์ชันประจำชนิดข้อมูล) ซึ่งก็คือฟังก์ชันธรรมดา ๆ ที่วางอยู่ข้างในบล็อก `impl` นั่นเอง:

```rust ,ignore
impl List {
    pub fn new() -> Self {
        List { head: Link::Empty }
    }
}
```

ข้อสังเกตเล็ก ๆ น้อย ๆ เกี่ยวกับโค้ดนี้:

* `Self` เป็น alias ย่อมาจาก "ชนิดข้อมูลที่เราเพิ่งเขียนไปข้างบนตรงข้าง ๆ คีย์เวิร์ด `impl`" เหมาะมากสำหรับการช่วยให้เราไม่ต้องพิมพ์ชื่อชนิดข้อมูลซ้ำไปซ้ำมา!
* เราสร้างอินสแตนซ์ของ struct ด้วยไวยากรณ์ที่แทบจะเหมือนตอนที่เราประกาศมันเลย เพียงแต่เปลี่ยนจากการระบุชนิดข้อมูลของแต่ละฟิลด์ มาเป็นการกำหนดค่าเริ่มต้น (value) ให้กับฟิลด์นั้น ๆ แทน
* เราเข้าถึงวาเรียนต์ของ enum โดยใช้เครื่องหมาย `::` ซึ่งเป็นตัวดำเนินการระบุเนมสเปซ (namespacing operator)
* นิพจน์ (expression) บรรทัดสุดท้ายของฟังก์ชันจะถูกส่งกลับ (return) ออกไปโดยอัตโนมัติ ช่วยให้ฟังก์ชันสั้น ๆ ดูสะอาดตาและเป็นระเบียบขึ้นมาก แต่ถ้าอยากจะคืนค่าเพื่อจบการทำงานก่อนเวลา (early return) คุณก็ยังใช้คีย์เวิร์ด `return` ได้เหมือนกับภาษาตระกูล C ทั่วไป
