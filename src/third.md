# สแต็กแบบซิงกลีลิงก์เพอร์ซิสเทนต์

เอาล่ะ เราเชี่ยวชาญศิลปะของสแต็กเชื่อมโยงทางเดียวแบบแก้ไขค่าได้ (mutable singly-linked stack) กันไปแล้ว

คราวนี้มาเปลี่ยนจากการถือครองความเป็นเจ้าของแบบ*คนเดียว* (single ownership) สู่การเป็นเจ้าของ*ร่วมกัน* (shared ownership) ด้วยการเขียนลิงก์ลิสต์เชื่อมโยงทางเดียวแบบเพอร์ซิสเทนต์ที่เปลี่ยนแปลงค่าไม่ได้ (persistent immutable singly-linked list) กันดีกว่า นี่จะเป็นโครงสร้างลิสต์แบบที่โปรแกรมเมอร์สาย Functional ทั้งหลายคุ้นเคยและหลงรัก คุณสามารถดึงส่วนหัว (head) *หรือ* ส่วนหาง (tail) แล้วเอาหัวของตัวหนึ่งไปสวมเข้ากับหางของอีกตัวหนึ่งได้ตามใจชอบ... แล้วก็... มีแค่นั้นจริง ๆ นั่นแหละ! ความอิมมิวเทเบิล (Immutability) นี่มันช่างน่าหลงใหลจนถอนตัวไม่ขึ้นจริง ๆ

ตลอดกระบวนการนี้ เราจะได้ทำความคุ้นเคยกับ `Rc` และ `Arc` เป็นหลัก ซึ่งนี่จะเป็นการปูพื้นฐานชั้นดีสำหรับลิสต์ถัดไปที่จะ*พลิกโฉมทุกสิ่งอย่างสิ้นเชิง*

มาสร้างไฟล์ใหม่ชื่อ `third.rs` กันเลย:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
```

รอบนี้ไม่มีการก็อปแปะโค้ดเดิมอีกแล้วนะ นี่คือการเริ่มสร้างใหม่ทั้งหมดตั้งแต่ศูนย์ (clean room operation)
