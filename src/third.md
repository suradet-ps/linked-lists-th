# สแต็กแบบซิงกลีลิงก์เพอร์ซิสเทนต์

เอาล่ะ เราเชี่ยวชาญศิลปะของสแต็กแบบซิงกลีลิงก์ที่กลายพันธุ์ได้แล้ว

มาเปลี่ยนจากความเป็นเจ้าของ*เดี่ยว*เป็นความเป็นเจ้าของ*ร่วม*ด้วยการเขียน
ลิงก์ลิสต์แบบซิงกลีลิงก์อิมมิวเทเบิลแบบเพอร์ซิสเทนต์ นี่จะเป็นลิสต์ที่
โปรแกรมเมอร์เชิงฟังก์ชันคุ้นเคยและรัก คุณสามารถเอาหัว*หรือ*หาง
และเอาหัวของคนหนึ่งไปใส่บนหางของอีกคนหนึ่ง...
และ... นั่นคือทั้งหมด อิมมิวเทบิลิตี้เป็นยาเสพติดชั้นยอด

ในกระบวนการเราจะคุ้นเคยกับ Rc และ Arc เป็นส่วนใหญ่ แต่มันจะ
ตั้งเราให้พร้อมสำหรับลิสต์ถัดไปที่จะ*เปลี่ยนเกม*

มาเพิ่มไฟล์ใหม่ชื่อ `third.rs`:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
```

ไม่มีก๊อปแปะครั้งนี้ นี่คือการดำเนินงานแบบ clean room
