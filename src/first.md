# สแต็กแบบซิงกลีลิงก์ที่แย่

บทนี้จะ*ยาวที่สุด*แบบเทียบไม่ติดเลย เพราะเราต้องแนะนำ Rust เกือบทั้งหมด
และเราจะสร้างหลายอย่างด้วย "วิธียาก" เพื่อให้เข้าใจภาษาได้ดีขึ้น

เราจะใส่ลิสต์แรกของเราใน `src/first.rs` เราต้องบอก Rust ว่า `first.rs`
เป็นสิ่งที่ lib ของเราใช้งาน ทั้งหมดที่ต้องทำคือเพิ่มบรรทัดนี้ไว้บนสุดของ
`src/lib.rs` (ซึ่ง Cargo สร้างไว้ให้เราแล้ว):

```rust ,ignore
// in lib.rs
pub mod first;
```
