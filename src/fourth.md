# เดกปลอดภัยแต่แย่

ตอนนี้เราได้เห็น Rc และได้ยินเกี่ยวกับมิวเทบิลิตี้ภายในแล้ว นี่ให้แนวคิดที่น่าสนใจ...
บางทีเรา*อาจ*เปลี่ยนแปลงข้อมูลผ่าน Rc ได้ และถ้าเป็นแบบนั้น
บางทีเราอาจใช้ลิสต์แบบ*ลิงก์คู่*ได้อย่างปลอดภัยทั้งหมด!

ในกระบวนการเราจะคุ้นเคยกับ*มิวเทบิลิตี้ภายใน* และคงจะเรียนรู้
วิธีที่ยากว่าปลอดภัยไม่ได้หมายความว่า*ถูกต้อง* ลิงก์ลิสต์แบบลิงก์คู่นั้นยาก
และผมมักจะทำผิดพลาดสักแห่งเสมอ

มาเพิ่มไฟล์ใหม่ชื่อ `fourth.rs`:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
pub mod fourth;
```

นี่จะเป็นการดำเนินงานแบบ clean room อีกครั้ง แม้ว่าตามปกติเราจะพบ
ตรรกะบางอย่างที่ใช้ได้เหมือนเดิมก็ตาม

หมายเหตุ: บทนี้เป็นการสาธิตว่าทำไมนี่ถึงเป็นความคิดที่แย่มาก
