# คิวซิงกลีลิงก์ unsafe ที่พอใช้ได้

โอเค เรื่องราวของ interior mutability บนพอยน์เตอร์แบบ reference-counted เมื่อกี้มันเริ่มจะเตลิดเปิดเปิงจนกู่ไม่กลับไปหน่อยแล้ว แน่นอนว่า Rust คงไม่ได้คาดหวังให้เราต้องมานั่งเขียนโค้ดทรมานทรกรรมแบบนั้นเป็นเรื่องปกติทั่วไปหรอกใช่ไหม? อืม... จะว่าใช่ก็ใช่ จะว่าไม่ใช่ก็ไม่เชิงครับ เจ้าคู่หู `Rc` กับ `RefCell` มันอาจจะยอดเยี่ยมมากสำหรับกรณีใช้งานง่าย ๆ ทั่วไป แต่พวกมันก็สามารถกลายร่างเป็นความเทอะทะยุ่งเหยิงได้ง่ายมากเช่นกัน โดยเฉพาะอย่างยิ่งเวลาที่คุณอยากจะปกปิดไม่ให้ใครรู้ว่าเบื้องหลังมันกำลังทำอะไรอยู่... มันต้องมีหนทางที่ดีกว่านี้สิ!

ในบทนี้ เราจะถอยกลับมาตั้งหลักที่ลิงก์ลิสต์แบบเชื่อมโยงทางเดียว (singly-linked list) อีกครั้ง และลงมือสร้างคิวแบบเชื่อมโยงทางเดียว (singly-linked queue) เพื่อหยั่งเชิงจุ่มเท้าลงไปสัมผัสกับโลกของ *พอยน์เตอร์ดิบ (raw pointers)* และ *Unsafe Rust*

> **ผู้บรรยาย:** และผมจะคอยชี้จุดผิดพลาดให้ดู

และเราจะไม่ทำผิดพลาดอะไร *เลยสักนิดเดียว* (หึ ๆ)

มาสร้างไฟล์ใหม่ชื่อ `fifth.rs` กันเลย:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
pub mod fourth;
pub mod fifth;
```

โค้ดของเราส่วนใหญ่จะต่อยอดมาจาก `second.rs` เพราะในโลกของลิงก์ลิสต์นั้น โครงสร้างแบบคิวก็เปรียบเสมือนการต่อเติมอัปเกรดสแต็กขึ้นมาอีกขั้นหนึ่ง แต่ถึงอย่างนั้น เราก็จะลงมือเขียนใหม่ทั้งหมดตั้งแต่ศูนย์ เพราะมีประเด็นพื้นฐานสำคัญบางเรื่องเกี่ยวกับโครงสร้างเมโมรี (layout) และสารพัดสิ่งที่เราต้องการจะจัดการให้ถูกต้องเสียก่อน
