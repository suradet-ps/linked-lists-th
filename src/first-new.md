# การสร้าง (New)

ในการเชื่อมโค้ดจริงเข้ากับชนิดหนึ่ง เราจะใช้บล็อก `impl`:

```rust ,ignore
impl List {
    // TODO, make code happen
}
```

ตอนนี้เราแค่ต้องหาว่าจะเขียนโค้ดจริงยังไง ใน Rust เราประกาศฟังก์ชันแบบนี้:

```rust ,ignore
fn foo(arg1: Type1, arg2: Type2) -> ReturnType {
    // body
}
```

สิ่งแรกที่เราต้องการคือวิธี*สร้าง*ลิสต์ เนื่องจากเราซ่อนรายละเอียดการนำไปปฏิบัติ
เราจึงต้องจัดหามันในรูปแบบฟังก์ชัน วิธีปกติในการทำแบบนั้นใน Rust คือการให้
เมธอดแบบสแตติก ซึ่งก็คือฟังก์ชันธรรมดาที่อยู่ภายใน `impl`:

```rust ,ignore
impl List {
    pub fn new() -> Self {
        List { head: Link::Empty }
    }
}
```

ข้อสังเกตเล็กน้อยเกี่ยวกับโค้ดนี้:

* Self คือนามแฝงของ "ชนิดที่ฉันเขียนไว้ด้านบนถัดจาก `impl`" เยี่ยมมากสำหรับ
  การไม่ต้องเขียนซ้ำ!
* เราสร้างอินสแตนซ์ของ struct ในแบบเดียวกับที่เราประกาศมัน เว้นแต่แทนที่จะ
  ระบุชนิดของฟิลด์ เรากลับกำหนดค่าเริ่มต้นให้กับมันด้วยค่า
* เราอ้างถึงวาเรียนต์ของ enum ด้วย `::` ซึ่งเป็นโอเปอเรเตอร์การแบ่งเนมสเปซ
* นิพจน์สุดท้ายของฟังก์ชันจะถูก return กลับไปโดยปริยาย
  สิ่งนี้ทำให้ฟังก์ชันง่าย ๆ ดูเป็นระเบียบขึ้นเล็กน้อย คุณยังสามารถใช้ `return`
  เพื่อคืนค่าแล้วออกจากฟังก์ชันก่อนเวลาได้เหมือนภาษาในตระกูล C อื่น ๆ
