# เดกปลอดภัยแต่แย่

หลังจากที่เราได้เห็น `Rc` และได้ยินเรื่อง interior mutability กันมาแล้ว มันก็ชวนให้เกิดความคิดน่าสนใจขึ้นมาว่า... บางทีเรา *อาจจะ* แก้ไขค่าผ่าน `Rc` ได้ก็ได้นะ? และถ้าทำแบบนั้นได้จริง บางทีเราอาจจะเขียนเดก/ลิงก์ลิสต์แบบ *เชื่อมโยงสองทาง (doubly-linked)* ออกมาได้อย่างปลอดภัย 100% (safe Rust) เลยก็เป็นได้!

ตลอดการทำสิ่งนี้ เราจะได้ทำความคุ้นเคยกับ *Interior Mutability (การแก้ไขค่าจากภายใน)* อย่างลึกซึ้ง และคงจะได้เรียนรู้บทเรียนราคาแพง (the hard way) ว่า ปลอดภัย (safe) ไม่ได้แปลว่า *ถูกต้อง (correct)* เสมอไป... ลิงก์ลิสต์แบบเชื่อมโยงสองทางนี่มันยากจริง ๆ นะครับ และตัวผมเองก็มักจะเผลอทำพลาดตรงไหนสักแห่งอยู่เสมอ

มาสร้างไฟล์ใหม่ชื่อ `fourth.rs` กันเลย:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
pub mod fourth;
```

นี่จะเป็นการเริ่มเขียนใหม่ตั้งแต่ศูนย์ (clean-room operation) อีกครั้ง ถึงแม้ว่าตามธรรมเนียมแล้ว เราอาจจะได้เจอโค้ดบางท่อนที่ยกมาใช้ซ้ำได้เหมือนเดิมเป๊ะ ๆ ก็ตาม
