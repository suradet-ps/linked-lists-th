# Unsafe Rust

นี่คือหัวข้อที่จริงจัง ใหญ่ ซับซ้อน และอันตราย
มันจริงจังมากจนผมเขียน [หนังสือเล่มอื่นทั้งหมด][nom] เกี่ยวกับมัน

สรุปสั้นๆ คือ *ทุก*ภาษาจริงๆ แล้วไม่ปลอดภัยทันทีที่คุณอนุญาตให้เรียกใช้
ภาษาอื่น เพราะคุณสามารถให้ C ทำสิ่งที่แย่มากแบบ arbitrily ได้ ใช่: Java,
Python, Ruby, Haskell... ทุกคนไม่ปลอดภัยอย่างรุนแรงเมื่อพบ Foreign Function
Interfaces (FFI)

Rust ยอมรับความจริงนี้โดยแบ่งตัวเองออกเป็นสองภาษา: Safe Rust และ
Unsafe Rust จนถึงตอนนี้เราใช้แค่ Safe Rust มัน 100% ปลอดภัย...
ยกเว้นว่ามันสามารถ FFI เข้าไปใน Unsafe Rust

Unsafe Rust เป็น *superset* ของ Safe Rust มันเหมือนกันทุกประการกับ
Safe Rust ในทุกอรรถศาสตร์และกฎ คุณแค่ได้รับอนุญาตให้ทำบาง*พิเศษ*ที่
ไม่ปลอดภัยอย่างรุนแรงและสามารถทำให้เกิด Undefined Behaviour ที่น่ากลัว
ที่หลอกหลอน C

อีกครั้ง นี่คือหัวข้อที่ใหญ่มากที่มีกรณีมุมที่น่าสนใจจำนวนมาก
ผม*จริงๆ* ไม่ต้องการลงลึกมาก (โอ้ ผมต้องการ ผมได้ [อ่านหนังสือ
เล่มนั้น][nom]) ไม่เป็นไร เพราะด้วยลิงก์ลิสต์เราสามารถเพิกเฉยได้จริงๆ
เกือบทั้งหมด

> **ผู้บรรยาย:** นี่คือคำโกหก แต่มันดูเหมือนจริงในปี 2015

เครื่องมือ Unsafe หลักที่เราจะใช้คือ *ตัวชี้ดิบ* ตัวชี้ดิบเป็น
พื้นฐานแล้วตัวชี้ของ C มันไม่มีกฎ aliasing โดยธรรมชาติ มันไม่มี
ไลฟ์ไทม์ มันเป็น null ได้ มันไม่ align กันได้ มันลอยได้ มันชี้ไปยัง
หน่วยความจำที่ยังไม่ได้ initialize มันสามารถ cast ไปเป็นจำนวนเต็มและกลับ
มันสามารถ cast ไปชี้ชนิดอื่น มิวเทบิลิตี้? cast มัน เกือบทุกอย่างผ่าน
และนั่นหมายความว่าเกือบทุกอย่างผิดพลาดได้

> **ผู้บรรยาย:** ไม่มีกฎ aliasing โดยธรรมชาติ เหรอ? อ่า ความไร้เดียงสาของเยาวชน

นี่คือสิ่งที่แย่และพูดตามตรงคุณจะมีชีวิตที่มีความสุขกว่าถ้าไม่เคย
แตะสิ่งเหล่านี้ โชคร้าย เราต้องการเขียนลิงก์ลิสต์ และลิงก์ลิสต์
น่ากลัว นั่นหมายความว่าเราจะต้องใช้ unsafe pointers

มีตัวชี้ดิบสองชนิด: `*const T` และ `*mut T` เหล่านี้หมายถึง
`const T*` และ `T*` จาก C แต่เราไม่สนว่า C คิดว่ามัน
หมายความว่าอะไร คุณสามารถ dereference `*const T` เป็น `&T` เท่านั้น แต่เหมือนกับ
มิวเทบิลิตี้ของตัวแปร นี่เป็นแค่ lint สำหรับการใช้งานที่ผิดพลาด อย่างมาก
มันหมายความว่าคุณต้อง cast `*const` เป็น `*mut` ก่อน แม้ว่าถ้า
คุณไม่มีสิทธิ์เปลี่ยนแปลงสิ่งที่ตัวชี้อ้างถึงจริงๆ คุณจะ
มีช่วงเวลาที่แย่

อย่างไรก็ตาม เราจะเข้าใจมันดีขึ้นเมื่อเราเขียนโค้ด ตอนนี้
`*mut T == &unchecked mut T`!
