# สแต็กแบบซิงกลีลิงก์ที่แย่

บทนี้จะ*ยาวที่สุด*แบบทิ้งห่างเพื่อนร่วมรุ่นแบบไม่เห็นฝุ่น เพราะเราจำเป็นต้องปูพื้นฐานแทบทุกอย่างของ Rust และเราจะค่อย ๆ ประกอบร่างสิ่งต่าง ๆ ขึ้นมาด้วย "วิธียาก" (the hard way) เพื่อช่วยให้คุณเข้าใจภาษาได้ลึกซึ้งยิ่งขึ้น

เราจะเก็บโค้ดลิสต์ตัวแรกของเราไว้ใน `src/first.rs` โดยเราต้องบอก Rust ให้รู้ว่า `first.rs` เป็นส่วนหนึ่งที่ไลบรารีของเราเรียกใช้ ซึ่งทั้งหมดที่ต้องทำก็แค่ใส่บรรทัดนี้ไว้ที่บนสุดของไฟล์ `src/lib.rs` (ที่ Cargo สร้างไว้ให้เราเรียบร้อยแล้ว):

```rust ,ignore
// in lib.rs
pub mod first;
```
