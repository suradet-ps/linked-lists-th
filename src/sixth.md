# เดกสองทางแบบ Unsafe คุณภาพระดับโปรดักชัน

ในที่สุดเราก็มาถึงจนได้ ศัตรูตัวฉกาจที่สุดของข้า: **[std::collections::LinkedList][linked-list] เดกสองทาง (Doubly-Linked Deque)**

สิ่งมีชีวิตที่ข้าเคยพยายามจะทำลายล้าง แต่กลับล้มเหลวไม่เป็นท่า

เรื่องราวของเราเริ่มต้นขึ้นเมื่อช่วงปลายปี 2014 ขณะที่เรากำลังก้าวเข้าใกล้การเปิดตัว Rust 1.0 ซึ่งเป็นเวอร์ชันเสถียรตัวแรกของ Rust ข้าพบว่าตัวเองต้องมารับบทบาทเป็นผู้ดูแล `std::collections` หรือที่พวกเราเรียกกันติดปากในยุคนั้นด้วยความรักใคร่ว่า libcollections

libcollections ในเวลานั้นได้ผ่านช่วงเวลาหลายปีของการเป็นที่ทิ้งไอเดียกุ๊กกิ๊กกับของที่พอดูมีประโยชน์บ้างของทุกคน ซึ่งตอนที่ Rust ยังเป็นเพียงภาษาทดลองที่เพิ่งตั้งไข่มันก็ดีอยู่หรอก แต่ถ้าลูกๆ ของข้าจะต้องกางปีกบินออกจากรังและได้รับการรับรองเสถียรภาพ (stabilized) พวกมันก็ต้องพิสูจน์คุณค่าของตัวเองให้ประจักษ์เสียก่อน

ก่อนหน้านั้น ข้าเคยโอบอุ้มและฟูมฟักพวกมันทั้งหมดมาโดยตลอด แต่นี่ถึงเวลาแล้วที่พวกมันจะต้องเผชิญหน้ากับการพิพากษาต่อข้อบกพร่องของตน

ข้าจิกกรงเล็บลงบนแผ่นหินผาและสลักป้ายหลุมศพให้แก่ลูกๆ ผู้โง่เขลาที่สุดของข้า... อนุสรณ์สถานอันน่าสยดสยองที่ข้าตั้งตระหง่านไว้กลางจัตุรัสเมืองเพื่อให้ทุกคนได้ประจักษ์แก่สายตา:

**[Kill TreeMap, TreeSet, TrieMap, TrieSet, LruCache and EnumSet](https://github.com/rust-lang/rust/pull/19955)**

ชะตากรรมของพวกมันถูกผนึกไว้แล้ว เพราะวาจาของข้าถือเป็นประกาศิตเด็ดขาด คอลเลกชันอื่นๆ ต่างพากันขวัญผวาต่อความเหี้ยมโหดของข้า ทว่าพวกมันก็ยังไม่รอดพ้นจากเพลิงพิโรธของมารดาผู้นี้อยู่ดี ไม่นานนัก ข้าก็หวนกลับมาพร้อมป้ายหลุมศพอีกสองแผ่น:

**[Deprecate BitSet and BitVec](https://github.com/rust-lang/rust/pull/26034)**

คู่แฝด Bit นั้นเจ้าเล่ห์เพทุบายกว่าสหายร่วมศึกที่ล้มตายไป ทว่าพวกมันยังขาดพลังที่จะดิ้นรนหนีรอดจากเงื้อมมือของข้า คนส่วนใหญ่คิดว่างานของข้าเสร็จสิ้นลงแล้ว แต่ไม่นาน ข้าก็ปลิดชีพไปอีกหนึ่ง:

**[Deprecate VecMap](https://github.com/rust-lang/rust/pull/26734)**

VecMap พยายามจะเอาชีวิตรอดด้วยการหลบซ่อนตัว &mdash; มันช่างตัวเล็กจ้อยและไร้พิษสง! แต่นั่นยังไม่คู่ควรพอสำหรับ libcollections ในมโนภาพแห่งอนาคตของข้า

ข้ากวาดสายตาสำรวจผืนแผ่นดินและชื่นชมสิ่งที่ยังคงหลงเหลืออยู่:

* Vec และ VecDeque - แข็งแกร่ง บึกบึน และเรียบง่าย หัวใจหลักแห่งการประมวลผล
* HashMap และ HashSet - ทรงพลังและชาญฉลาด มันสมองแห่งการประมวลผล
* BTreeMap และ BTreeSet - พิลึกกึกกือแต่ขาดไม่ได้ ตับแห่งการประมวลผล
* BinaryHeap - ปราดเปรียวและคล่องแคล่ว ข้อเท้าแห่งการประมวลผล

ข้าพยักหน้าด้วยความพึงพอใจ... เรียบง่ายและทรงประสิทธิภาพ งานของข้าเสร็จสิ้นเสี&mdash;

อย่านะ! [DList](https://github.com/rust-lang/rust/blob/0a84308ebaaafb8fd89b2fd7c235198e3ec21384/src/libcollections/dlist.rs) เป็นไปไม่ได้! ข้านึกว่าเจ้าตายไปแล้วในโศกนาฏกรรมอุบัติเหตุเก็บขยะ (garbage collection) ครั้งนั้นเสียอีก! เหตุการณ์ที่แน่นอนที่สุดว่ามันเป็นแค่อุบัติเหตุและไม่ได้มีใครจงใจเลยสักนิดเดียว!

พวกมันแกล้งตายแล้วชุบตัวขึ้นมาใหม่ด้วยชื่อใหม่ ทว่าเนื้อในก็ยังคงเป็นมันอยู่วันยังค่ำ: LinkedList เจ้าจอมบงการผู้น่าเคลือบแคลงและชั่วร้ายแห่งวงการคอมพิวเตอร์

ข้าป่าวประกาศความชั่วร้ายของมันให้ทุกคนที่พร้อมจะรับฟัง แต่หัวใจของพวกเขากลับด้านชาไร้ความรู้สึก LinkedList มันคือปีศาจจอมลิ้นทองที่คอยเป่าหูทุกคนรอบตัวข้าให้หลงเชื่อว่ามันคือโครงสร้างข้อมูลพื้นฐานอันแสนเป็นธรรมชาติของศาสตร์คอมพิวเตอร์ มันถึงขั้นไปล่อลวงภาษา C++ ให้หลงเชื่อว่ามันคือ [*เดอะ* ลิสต์ (the list)](https://en.cppreference.com/w/cpp/container/list) เลยด้วยซ้ำ!

"จะมี standard library โดยไม่มี *LinkedList* ได้อย่างไรกันเล่า?"

ทำไมจะไม่มีไม่ได้ล่ะ! สบายมากเลยด้วยซ้ำ!

"ก็มันเป็น unsafe code ที่ซับซ้อนนี่นา การมีมันไว้ใน standard library จึงสมเหตุสมผลที่สุดแล้ว!"

พวกไดรเวอร์ GPU กับวิดีโอโคเดกก็ซับซ้อนพอกันแหละโว้ย! ปรัชญาของ libcollections คือมินิมอลต่างหากเล่า!

แต่อนิจจา LinkedList ได้รวบรวมพรรคพวกมากเกินไปและเติบใหญ่จนแข็งแกร่งเกินต้านทาน ในช่วงเวลาที่ข้าเสียสมาธิไปกับการไล่เช็กบิลเผ่าพันธุ์ของมัน

ข้าหนีกลับไปกบดานที่ห้องทดลองเพื่อคิดค้น [ร่างโคลนปีศาจ](https://github.com/contain-rs/linked-list) หรือไม่ก็ [หุ่นไซบอร์กสังหารกลายพันธุ์](https://github.com/contain-rs/blist) ขึ้นมาเพื่อหวังจะต่อกรและบดขยี้มันให้แหลกคามือ แต่แล้วเงินทุนวิจัยของข้ากลับถูกตัด เพราะงานวิจัยของข้าถูกตราหน้าว่า "มุ่งร้ายอำมหิตเกินไป" หรืออะไรเทือกนั้น

LinkedList เป็นฝ่ายชนะ... ข้าพ่ายแพ้ยับเยินและถูกเนรเทศออกไป

แต่ตอนนี้เจ้ามาอยู่ที่นี่แล้ว เจ้าอุตส่าห์ดั้นด้นเดินทางมาไกลถึงเพียงนี้ แน่นอนว่าเจ้าคงตระหนักซึ้งถึงความเลวทรามต่ำช้าของ LinkedList ดีแล้วใช่ไหมล่ะ! มาสิ... ข้าจะถ่ายทอดทุกสิ่งทุกอย่างที่เจ้าจำเป็นต้องรู้ เพื่อช่วยข้าสังหารมันให้ดับสูญไปตลอดกาล &mdash; ทุกสิ่งทุกอย่างที่เจ้าต้องรู้เพื่ออิมพลีเมนต์เดกสองทางแบบ unsafe คุณภาพระดับโปรดักชัน

คุณภาพระดับโปรดักชันขนาดไหนน่ะเหรอ? ก็ถึงขนาดที่เราจะมารื้อเขียน crate linked-list โบราณยุค Rust 1.0 ของข้าขึ้นมาใหม่ทั้งหมดเลยน่ะสิ แครตตัวที่พูดได้เต็มปากว่าดีกว่าตัวที่อยู่ใน std อย่างเทียบไม่ติด ตัวที่มี Cursor ให้ใช้บน stable Rust มาตั้งแต่ปี 2015! ในขณะที่ stdlib ปี 2022 ยังไม่มีปัญญาทำเลยด้วยซ้ำ!
