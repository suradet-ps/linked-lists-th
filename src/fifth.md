# คิวซิงกลีลิงก์ unsafe ที่พอใช้ได้

โอเค อะไรพวกนั้นที่ใช้ interior mutability แบบ reference-counted มันเริ่มหลุดมือ
ไปแล้ว Rust ไม่ได้คาดหวังให้คุณทำแบบนั้นโดยทั่วไปจริงๆ? ทั้งใช่และไม่ใช่
Rc และ RefCell อาจดีสำหรับจัดการกรณีง่ายๆ แต่มันจะยุ่งยาก โดยเฉพาะถ้าคุณ
ต้องการซ่อนว่ามันกำลังเกิดขึ้น ต้องมีวิธีที่ดีกว่า!

ในบทนี้เราจะย้อนกลับไปลิงก์ลิสต์แบบซิงกลีลิงก์และ
implement คิวแบบซิงกลีลิงก์เพื่อแตะ*ตัวชี้ดิบ*และ
*Rust ที่ไม่ปลอดภัย*

> **ผู้บรรยาย:** และผมจะชี้ข้อผิดพลาด

และเราจะไม่ทำ*ผิดพลาด*ใดๆ

มาเพิ่มไฟล์ใหม่ชื่อ `fifth.rs`:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
pub mod third;
pub mod fourth;
pub mod fifth;
```

โค้ดของเราส่วนใหญ่จะมาจาก second.rs เพราะคิวเป็น
การเพิ่มเติมของสแต็กในโลกของลิงก์ลิสต์ ยังคงเราจะ
เริ่มจากศูนย์เพราะมีปัญหาพื้นฐานที่เราต้องการ
จัดการกับโครงสร้างและอะไรทำนองนั้น
