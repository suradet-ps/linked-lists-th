# สแต็กแบบซิงกลีลิงก์ที่พอใช้ได้

ในบทก่อนหน้าเราเขียนสแต็กแบบซิงกลีลิงก์ขั้นต่ำที่ใช้ได้จริง (minimum viable)
แต่มีการตัดสินใจออกแบบหลายอย่างที่ทำให้มันแย่ มาทำให้มันแย่น้อยลงกัน
ในการทำแบบนั้น เราจะ:

* ประดิษฐ์ล้อใหม่
* ทำให้ลิสต์ของเราจัดการชนิดองค์ประกอบใดก็ได้
* เพิ่มการมอง (peek)
* ทำให้ลิสต์ของเราวนซ้ำได้ (iterable)

และในกระบวนการเราจะได้เรียนรู้เกี่ยวกับ

* การใช้ Option ขั้นสูง
* เจเนอริก
* ไลฟ์ไทม์
* อิเทอเรเตอร์

มาเพิ่มไฟล์ใหม่ชื่อ `second.rs`:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
```

แล้วคัดลอกทุกอย่างจาก `first.rs` เข้าไปในนั้น
