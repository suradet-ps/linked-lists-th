# สแต็กแบบซิงกลีลิงก์ที่พอใช้ได้

ในบทที่แล้ว เราได้ลงมือเขียนสแต็กแบบซิงกลีลิงก์เวอร์ชันใช้งานขั้นต่ำ (minimum viable) ไปเรียบร้อยแล้ว แต่การตัดสินใจในเชิงการออกแบบบางอย่างยังทำให้มันค่อนข้างห่วยอยู่พอสมควร ในบทนี้ เราจะมาทำให้มันหายห่วยกัน โดยสิ่งที่เราจะทำก็คือ:

* เลิกประดิษฐ์ล้อซ้ำซาก (Deinvent the wheel — หันมาพึ่งพาของมาตรฐานแทน)
* ปรับให้ลิสต์ของเรารองรับข้อมูลชนิดใดก็ได้ (Generics)
* เพิ่มฟังก์ชันสำหรับแอบส่องดูข้อมูล (Peeking)
* ทำให้ลิสต์ของเราสามารถวนลูปอ่านข้อมูลได้ (Iterable)

และในระหว่างทาง เราจะได้เรียนรู้เกี่ยวกับ:

* การใช้งาน `Option` ขั้นสูง
* เจเนอริก (Generics)
* ไลฟ์ไทม์ (Lifetimes)
* อิเทอเรเตอร์ (Iterators)

งั้นมาสร้างไฟล์ใหม่ชื่อ `second.rs` กันเลย:

```rust ,ignore
// in lib.rs

pub mod first;
pub mod second;
```

จากนั้นก็ก็อปปี้โค้ดทุกอย่างจาก `first.rs` มาใส่ไว้ในไฟล์นี้ได้เลย
